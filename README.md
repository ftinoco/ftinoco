<h2 align="center">🚀 About Me</h2>

I'm a Software Engineer specializing in the .NET ecosystem, with extensive experience designing and building scalable backend systems for production environments.

My work focuses on creating software that is reliable, maintainable, and easy to evolve. I enjoy translating complex business requirements into well-designed architectures, optimizing system performance, and delivering solutions that balance technical excellence with business value.

Over the years, I've worked across the full software development lifecycle, contributing to backend services, APIs, distributed systems, database design, cloud-native applications, observability, and modern DevOps practices. While my primary expertise is in C# and ASP.NET Core, I'm comfortable working across the stack whenever the problem requires it.

I'm particularly interested in:

- Designing scalable distributed systems
- Software architecture and domain modeling
- High-performance backend development
- Cloud platforms and containerized workloads
- Engineering best practices, code quality, and continuous improvement

<!--Outside of my professional work, I enjoy building products from the ground up. I'm currently developing Kallisto, an inventory and business management platform, where I apply the same engineering principles used in large-scale production systems to solve real-world business problems.-->

I believe great software is built through thoughtful design, continuous learning, and close collaboration. I'm always interested in tackling challenging engineering problems and building systems that stand the test of time.
